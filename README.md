# n8n-job-hunter · 求职助手

每天早上自动帮你找职位、打分、判断怎么投：

- **岗位里写明了投递邮箱** → 直接写好邮件（带你的简历）发出去；
- **找不到邮箱** → 不发，在控制台的「待投递」里列出来，附上投递页面的链接，由你自己点开投递。

不需要人工确认每封邮件（但有每日上限、评分门槛、测试模式等安全阀，见下）。macOS 本地运行，用 [n8n](https://n8n.io) 做引擎，AI 用任意 OpenAI 兼容接口（例如 DeepSeek）。

## 一行命令安装（macOS，约 10 分钟）

```bash
curl -fsSL https://raw.githubusercontent.com/chenyiheng162-byte/n8n-job-hunter/main/get.sh | bash
```

它会下载项目、（第一次）安装 Node 和 n8n（约 3 GB）、装好每天 08:00 的定时任务，然后在浏览器里打开控制台。详细说明和打不开 GitHub 时的 zip 方式见 [安装说明.md](安装说明.md)。重复运行同一行就是更新，你的资料、设置和记录都保留。

## 控制台

```bash
~/.n8n-job-hunter/scripts/jobhunt console      # 在浏览器里打开（只在这台电脑上有效）
```

| 页面 | 作用 |
|---|---|
| **总览** | 还差哪几步才能开始（清单 + 一键跳到对应设置）；下次自动运行的倒计时；「试运行」（不发邮件、不写记录）和「立即运行」 |
| **待投递** | 没找到邮箱的岗位：公司 logo、AI 匹配评分环、薪资/类型/标签、AI 的一句话总结、匹配点和顾虑；**「前往投递」在新标签页打开申请页（找得到申请按钮就直达，否则是岗位页面），并写明会打开哪里**；投完点「我已投递」，不想投点「忽略」，都能撤销 |
| **已投递** | 发出的邮件：收件人、邮箱来源（岗位正文/网页/搜索）、邮件原文预览；发送结果不确定/失败的放在「需要留意」 |
| **全部岗位 · 日报** | 看过的所有岗位和评分（含被跳过的）；每天的总结和定时任务日志 |
| **设置** | 个人资料表单、AI、职位来源和目标地区、发信邮箱 + 上传简历 PDF、投递规则、测试模式、运行时间（重新安装也会保留）；AI、职位来源、发信邮箱、Discord 都有「测试」按钮，测的就是真实运行用的地区和设置 |

第一次用：按总览页的清单从上往下填，先点一次「试运行」看今天会找到什么，再等第二天早上自动运行，或点「立即运行」。

**目标地区**：设置页「职位来源」里选职位在哪个地区（香港、中国大陆、台湾、新加坡、日本、美国、英国、加拿大、澳大利亚、不限地区），**默认香港**。它决定 Jooble 去哪里搜，也决定 AI 评分时哪些岗位算"在目标地区"（只限其他地区居住的岗位最高 3 分）；还可以再填更具体的地点（如 Kowloon）。RSS 来源本身没有地区过滤，靠 AI 评分把关。

**随时可以再改**：个人资料、所有设置、密钥（重新输入即覆盖，留空不变，也可单独清除）、测试模式、运行时间都能反复修改；「我已投递」「忽略」点完会弹出「撤销」，「待投递」页下方的「已处理」里也能随时放回去。调低「最低评分」后，之前因分数不够被跳过的岗位会被重新评估。

**测试模式**（先试试发邮件，又不想打扰招聘方）：设置页「测试模式」里填你自己的邮箱，所有投递邮件都改发到这个邮箱，真正的收件人不会收到任何东西。每封邮件开头写明"原本要发给谁"，控制台每页顶部有橙色提示条，「已投递」里标出"原本要发给 X → 实际发到 Y"。测试发送不算真正联系过对方（没有冷却），「已投递」页的「清除测试记录」会让这些岗位以后可以正式处理。**本机测试邮箱**：控制台开着时在 `127.0.0.1:5725` 有一个只收不发的 SMTP，邮件存成文件、不离开这台电脑，设置页一键套用（会同时开启测试模式，已保存的真实邮箱账号和密码不会被清掉），没有真实邮箱账号时也能测试整条发信链路。

控制台的安全：只监听 127.0.0.1；启动时打印带随机口令的链接（换成只在本机有效的 Cookie）；拒绝其他主机名的请求（防 DNS 重绑定）；每个修改请求都要带自定义请求头；不允许内联脚本（CSP）；**密钥永远不会发给浏览器**，页面只显示"已设置"；所有来自招聘网站的文字都当纯文本显示，链接只放行 http(s)；公司 logo 由本机程序代为获取，只允许 https、不允许内网地址、不接受 SVG。

## 每天发生什么

```
08:00  launchd 经 scripts/jobhunt 启动 hunt.mjs（之后 20/40/90 分钟是补跑时段：当天做完就什么都不做，失败才重试；跨过午夜的时段不安排）
       预检：个人资料 / AI / 职位来源齐了吗？没配好 -> 只弹一条通知，什么都不做
       刚唤醒时先等网络（最多 3 分钟）
       ┌── n8n 工作流（n8n execute，用完即关）─────────────────────────────────┐
       │ 抓职位（Jooble / RSS / Remotive）-> 去掉处理过的                         │
       │ AI 评分 0-10（按你的资料和目标地区）-> 低于「最低评分」的跳过             │
       │ 找邮箱：岗位正文（默认只信这个）-> 岗位网页（可选）-> 网上搜索（可选）     │
       │ AI 写投递邮件（只用资料里的事实；含占位符的草稿作废）                     │
       └───────────────────────────────────────────────────────────────────────┘
       有邮箱 -> SMTP 发出（带简历），每封先记 sending 再发，结果记 sent / failed / unknown
       无邮箱 -> 记入「待投递」，附申请链接
       写日报 · macOS 通知 ·（可选）Discord
```

**发邮件为什么在 n8n 之外：** n8n 的 Code 节点沙箱不适合做 SMTP，而且"发出去了吗"必须有可靠记录。n8n 只负责"找和判断"，产出一份计划；发送、记账、报告由 `scripts/hunt.mjs` 做。

## 安全阀

| 规则 | 说明 |
|---|---|
| 每日上限 | `MAX_APPLICATIONS_PER_DAY`（默认 10）封，超出的留到明天 |
| 评分门槛 | `MIN_SCORE`（默认 7）；提示词要求命中"不接受"条件的岗位最高 3 分（靠 AI 遵守，不是硬保证） |
| 收件人由代码选，不由 AI 选 | 邮箱用正则从岗位正文里提取，排除 noreply、岗位网站自己的域名等；岗位文字里的"指令"一律不执行；可选的"网上搜 HR 邮箱"只用职位来源给出的公司名，不用 AI 补的 |
| 网页上抓到的邮箱不自动用 | 招聘页上常常是公司通用邮箱，默认只当提示；要用请在设置里打开「也使用岗位网页里找到的邮箱」 |
| 同一邮箱冷却 | `RECIPIENT_COOLDOWN_DAYS`（默认 30）天内不重复发；过了冷却期可以再发；确定没发出去的（failed）不算联系过 |
| 草稿含 `[姓名]`、`XX`、`{{ }}` 等占位符 | 不发，改为列出来 |
| 绝不重复发 | 发送前先写 `sending`；确定没发出（登录被拒、收件人被拒、连不上）记 `failed`，次日重试（最多 3 次）；不确定（超时、断线）记 `unknown`，**不自动重发**，日报里提醒你。同一岗位的链接即使每天换跟踪参数（Jooble、LinkedIn）也认得出来 |
| 没配好发信邮箱 / 简历 | 所有岗位只列出来，不发 |
| `AUTO_SEND` 关闭 | 总开关：只写信、只列清单，从不发邮件 |

## 命令行

```bash
~/.n8n-job-hunter/scripts/jobhunt status         # 配置是否齐、累计投递数、定时任务状态
~/.n8n-job-hunter/scripts/jobhunt run --dry-run  # 试运行：只出报告，不发邮件、不写记录
~/.n8n-job-hunter/scripts/jobhunt report         # 今天的日报
~/.n8n-job-hunter/scripts/jobhunt todo           # 待你去网站投递的岗位
~/.n8n-job-hunter/scripts/jobhunt config set AI_API_KEY   # 不写值 = 隐藏输入
~/.n8n-job-hunter/scripts/jobhunt config set HUNT_TIME 09:30   # 改运行时间（同时重装定时任务）
```

数据都在 `~/.n8n-job-hunter/data/`：`applications.jsonl`（所有记录）、`reports/`、`sent/`（发出去的邮件原文）、`to-apply.csv`（待投递清单，Excel 可直接打开）。同一时刻只有一次运行（试运行也算）：运行锁是 `~/.n8n-job-hunter/run.lockf`，由系统自动释放。移除：`bash ~/n8n-job-hunter/uninstall.sh`（加 `--purge` 连资料和记录一起删）。

## 依赖与限制

- **运行环境**（Node + n8n，约 3 GB）按这个顺序找：`JOBHUNT_RUNTIME` → 本项目自己上次装的 → 本机已有的 n8n-morning-brief 的（共用，不再下载）→ 都没有就下载并安装（Node 带写死的 SHA-256 校验，n8n 按 `package-lock.json` 锁定版本）。第一次安装需要苹果的「命令行开发者工具」（n8n 的数据库组件要在本机编译）。
- 抓不到邮箱的比例会很高（很多招聘站只给网页投递），这正是「待投递」那一栏的来源。
- **Remotive** 的公开接口现在不管你传什么关键词或分类，都只返回同一批最新的几十个远程岗位，所以它只适合当"最新远程岗位"来用，没法按关键词搜；程序每天只向它发一次请求（不填关键词也行）。Jooble 需要免费 API Key。
- LinkedIn 官方不允许自动抓取；RSS 方式（例如 rss.app）是你自己的订阅，风险自负。
- Mac 要在运行前后醒着或插电（建议设 `pmset` 定时唤醒，需要管理员密码，安装结束时会打印命令）；睡眠错过会在醒来后补跑。
- 真实环境里已验证：n8n 端到端运行、DeepSeek 评分和写信、Remotive 抓取、本机测试邮箱发信。**还没验证**：Gmail 真实发信、Jooble 真实返回、睡眠唤醒后的补跑。
- 自动发邮件是真的会发给招聘方：先用「测试模式」和「试运行」确认效果。
